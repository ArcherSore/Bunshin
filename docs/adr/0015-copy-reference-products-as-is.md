# 照搬参考产品时原样照搬，界面不展示内部细节

需求写明“照 MXU（或 MFAAvalonia）做”时，默认原样照搬它的行为和样式，不在其上加提示，也不先改造成本项目的样式再交付。内部边界情况（例如某些文件被占用而跳过）静默处理并写进日志，不显示给用户；界面上的数字有小误差不算缺陷。确有限制需要用户知道时，在对话里说明，不加界面文字。

## 考虑过的方案

- **在参考产品之上补充提示**：用户否决，“用户不需要知道这些细节”。
- **改成项目设计令牌的版本**：欢迎框比较过这一版，用户选了与 MXU 一致的样式（2026-11-08）。

## 依据

用户直接拍板。参考产品源码：[MXU](https://github.com/MaaXYZ/MXU)（`main`）、[MFAAvalonia](https://github.com/MaaXYZ/MFAAvalonia)（`master`），本地没有检出，用 `gh api` 读取。
