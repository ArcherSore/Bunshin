# 界面按 Claude 设计分析稿改版，同时上线深色

界面按用户用 Claude 做出的设计分析稿整体重做，浅色和深色一起上线。取舍如下：深色随改版一并提供，外观默认跟随系统；通知保留系统气泡，不自绘通知卡片；应用内的错误和确认框做成主窗口内的浮层，主窗口创建前的启动错误和第二个实例的“已在运行”提示仍用系统 MessageBox；运行面板的宽度范围、折叠和区块顺序由程序保存。

## 考虑过的方案

- **深色等以后再做**：ADR 0019 曾因色阶要重做而推迟深色；色阶定稿后一起做，避免同一批视图改两遍。
- **自绘通知卡片**：与系统通知中心脱节，且需要自管位置和时长，收益小，作为已接受的偏离。
- **所有对话框都换成自绘窗口**：启动早期和多实例场景没有可用的主窗口，保持系统 MessageBox 更可靠。

## 依据

用户拍板。设计稿是私有 artifact「Bunshin UI 重构」，不提交进仓库；实现范围见父 Issue #176。
