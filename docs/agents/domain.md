# 领域文档

本仓库采用单上下文布局：根目录 [GLOSSARY.md](../../GLOSSARY.md) 是项目术语表，[docs/adr/](../adr/) 只保存少数长期架构决策。

开始相关工作时读取术语表和涉及区域的 ADR，使用其中的推荐术语。若代码与术语或 ADR 冲突，先核对当前事实，再决定是否修正文档或提出新的设计选择。

只在术语实际形成或改变时更新 GLOSSARY.md；用一两句话定义概念，不写实现、流程或历史。只有决策同时难以逆转、未来读者会觉得意外、且确有合理替代方案时才新增 ADR。文件按需创建，不为一次讨论或已完成任务补文档。

docs/ARCHITECTURE.md 只描述当前系统的组件、边界、主要流转和不变量；稳定协议才保留独立 reference。
实现过程、测试输出、验收流水账、临时研究和讨论纪要不进长期文档，由 Git history 和 Issue/PR 承担。
不建归档目录保存过时内容；完成工作后清理失效链接与过期说明。
